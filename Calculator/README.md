# MSMS: Music School Management System

## Overview
Welcome to MSMS! This is an application built in Python to manage data of student and teacher at a music school. This app allows receptionists to register new students, enroll them in their preferred instruments, manage teacher records and perform searches. 

## Project Structure
MSMS.py # Main Python file that runs the application
README.md # Project documentation  

## FEATURES OF EACH FRAGMENT

### Student Management
- Register new students with ID that is generated by the program.
- Enroll students in their preferred instruments.
- Search for students by typing their name
- View all students that have registered and the courses that they have enrolled in.

### Teacher Management
- Teachers are added automatically by the program
- Search teachers by their name or instrument
- View all the teachers that are currently in the system

### Lookup
- Use any keyword to search for students, teachers and their specialties
- Doesn't matter if the word is in uppercase or lowercase, the app will still fins a match, ignoring the differences.

### Interactive Main Menu
- After every action, the menu appears again to allow the user to keep continuing without restarting the program, keeping it interactive.
- The user selects what they want to do by typing '1', '2', '3', '4', or '5' for different tasks or 'q' to exit the program.

## How to Run the Program
- Make sure you have already installed Python 3
1. Open Terminal or VS Code
2. Navigate to the folder containing the project
    cd MSMS-project
3. Run the program
    python3 MSMS.py
4. You will then see a menu appear in the terminal where you can:
    - Register new Students
    - Enrol existing students in instruments
    - Look up or search students/teachers
    - View all the students/teachers
    - Quit the application by typing 'q'

## How to Test the Program
- Start by choosing option 1 to register a new student.
- Then sure option 4 to check if the student was added.
- Try option 2 to enrol an existing student into another instrument.
- Use option 3 to test the Lookup feature by entering the name or instrument.
- Use option 5 to see the list of all the teachers.
- Choose 'q'to quit

## Design Choices
- All student and teacher data are stored in simple Python lists which are student_db and teacher_db, instead of a real database. 
- This program automatically gives each student and teacher a new ID using next_student_id and next_teacher_ID.
- A few teachers are added automatically like "Dr.Keys" and "Ms.Fret", making it easy for testing
- Divided code into different sections - data models, core functions, front desk actions, and main app - for organization. 
- The Lookup feature ignores capitalization when matching, making it more user-friendly.
- If the user enters a non-existent student ID or a wrong input, it shows an error message. 

## Assumptions
- Student names are unique enough to be identified 
- No to teachers have the exact same role
- Users will follow the menu instructions and enter valid input.
- Each student can enroll in multiple instruments that is stored in the list.
- The user that is running this program is the receptionist, therefore has permission to access everything.
